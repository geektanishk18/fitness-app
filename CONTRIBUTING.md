# Contributing

## Workflow

1. Read `AGENTS.md` and the playbooks relevant to the phase.
2. Confirm the current branch and clean/expected working tree.
3. Define acceptance criteria before implementation.
4. Make focused changes and update related documentation in the same phase.
5. Run the applicable checks and record actual results.
6. Review the diff for security, complexity, and accidental scope expansion.

Do not commit secrets, service-role keys, personal fitness data, or generated build output.

## Commit style

Use concise imperative messages such as `docs: establish project engineering guide` or `feat: add deterministic workout scheduler`.
