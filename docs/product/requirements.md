# Product Requirements

## MVP outcome

Help one user execute an adaptive hypertrophy program, log workouts, track nutrition and body changes, and receive basic data-driven coaching.

## Core requirements

- Installable, responsive dark PWA.
- Authenticated private user data.
- Four-, five-, and six-day scheduling from a six-day template with manual override.
- Workout sessions with exercises, sets, reps, weight, rest timer, history, and progression.
- Food entries with calories/macros and daily summary.
- Weight, measurements, photos, charts, and trend summaries.
- Server-side Groq coaching with bounded context and validated output.
