# Frontend Design

**Purpose:** Deliver a calm, premium, usable fitness interface.

**Use when:** Creating or changing screens, components, navigation, or responsive behavior.

**Principles:** Mobile-first layout, dark near-black surfaces, restrained accents, readable type, clear hierarchy, touch-safe controls, and accessible states.

**Workflow:** Define the user task, establish tokens, compose focused components, handle loading/empty/error states, then check narrow and wide viewports.

**Verification:** Keyboard access, contrast, semantic labels, responsive layout, and a critical Playwright flow.

**Avoid:** Decorative clutter, tiny touch targets, color-only status, and duplicated ad-hoc styles.
