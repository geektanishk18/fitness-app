# Context and Token Efficiency

**Purpose:** Preserve attention for useful engineering work.

**Use when:** Planning, investigating, reporting, or deciding what to read.

**Principles:** Read focused files, use repository docs as persistent context, summarize results, and avoid speculative branches.

**Workflow:** Identify the smallest evidence set, inspect only relevant files, make a reversible assumption when safe, and record decisions once.

**Verification:** The final report states changed files, actual checks, blockers, and next action without repeating requirements.

**Avoid:** Dumping whole files, rereading all docs every turn, installing tools without need, or implementing future phases early.
